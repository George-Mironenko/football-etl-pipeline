# Football ETL Pipeline

Проект **Football ETL Pipeline** — это система извлечения, трансформации и загрузки (ETL) данных о футбольных соревнованиях из публичного API в PostgreSQL.  
Цель — автоматизировать сбор данных и обеспечить их актуальность в базе данных для дальнейшего анализа.
Сейчас он на стадии разработки, но им уже можно пользоваться.

---

## 📦 Стек технологий

- **Python 3.10+**
- **Pandas** — обработка и трансформация данных
- **psycopg2** — подключение к PostgreSQL
- **python-dotenv** — управление переменными окружения
- **logging** — логирование процессов
- **colorama** — цветные логи в консоли
